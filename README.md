🐍 Snake Game in Java

A classic Snake Game built using Java Swing and AWT, featuring a colorful snake, animated movement, apples to eat, tail growth, score tracking, and collision detection.

🎮 Features
🐍 Realistic Snake Graphics – A green snake with a detailed head, eyes, and body.
🍎 Apple Collection – One apple appears at a time on the game board.
📈 Growing Tail – The snake grows longer whenever it eats an apple.
🏆 Score System – Earn 10 points for every apple eaten.
🧱 Border Collision – The game ends if the snake hits the border.
💥 Self-Collision Detection – The game ends if the snake hits its own body.
🔄 Restart Option – Press Space to restart after Game Over.
🎨 Enhanced Graphics – Green checkerboard background, a visible border, and a score display.
⌨️ Keyboard Controls – Control the snake using the arrow keys or W, A, S, D.
🛠️ Technologies Used
Java – Core programming language.
Java Swing – Game window and graphical interface.
Java AWT – Graphics rendering and keyboard input.
Java Timer – Controls the snake's movement.
📋 Requirements
Java Development Kit (JDK) 8 or later.
A Java-compatible IDE, such as IntelliJ IDEA, Eclipse, or VS Code, or a terminal.
🚀 How to Run
1. Clone the repository
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git


Replace YOUR-USERNAME and YOUR-REPOSITORY with your GitHub username and repository name.

2. Navigate to the project folder
cd YOUR-REPOSITORY

3. Compile the program
javac SnakeGame.java

4. Run the game
java SnakeGame


The game window will open, and you can start playing!

🎯 Controls
Key	Action
⬆️ Up Arrow / W	Move up
⬇️ Down Arrow / S	Move down
⬅️ Left Arrow / A	Move left
➡️ Right Arrow / D	Move right
Space	Restart after Game Over
📊 Scoring System
Start with a score of 0.
Eat an apple to earn 10 points.
Each apple makes the snake grow by one segment.
Avoid the walls and your own body to keep playing.
